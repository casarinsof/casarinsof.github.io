# casarinsof.github.io

Personal homepage of Sofia Casarin, served with GitHub Pages at <https://casarinsof.github.io>.

## Files

- `index.html` – page content
- `style.css` – styles
- `_config.yml` – Jekyll config (`jekyll-theme-minimal`, site title and description)
- `profile-pic.jpg`, `background.jpg` – images

## Editing locally

Open `index.html` in a browser to preview changes. For a Jekyll preview (optional, requires Ruby): `gem install jekyll bundler` and run `jekyll serve`, then open <http://localhost:4000>. Commit and push to `main` to publish.
